# Processo Seletivo NAUTTA — Leandro Alves

Site estático pronto para GitHub Pages ou Vercel.

## Publicar na Vercel
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js` para a raiz.
3. Na Vercel, importe o repositório.
4. Framework Preset: **Other**. Não é necessário comando de build.
5. Deploy.

## Editar respostas
Todas as respostas ficam no início de `script.js`, organizadas por categoria.

## Observação
O visual é inspirado na linguagem gráfica do material do processo seletivo, sem representar um site oficial da empresa.
